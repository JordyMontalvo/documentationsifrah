La herramienta diaria del distribuidor para operar su negocio independiente.

🔒 Seguridad & Billetera

Blindaje Contable (wallet-lock.js)

Mecanismo anti-concurrencia para prevenir el ataque de "doble gasto" cuando dos solicitudes de cobro llegan en el mismo milisegundo.

  • Locking por Usuario: Bloquea temporalmente el registro en Mongo durante la transacción.
  • Auto-Healer: Script que audita si la suma de bonos concuerda con el saldo de la billetera.
  • CORS Estricto: Whitelist estricta para solicitudes originadas desde Vercel o la App nativa.

Motor de Cierre de Periodos en Go (cierre_engine/)

La joya de rendimiento del proyecto: cómo Sifrah resolvió el cálculo masivo de bonos y rangos para miles de socios en menos de 15 segundos.

Golang 1.20+ Native Binary

1. Construcción del Árbol de Red

Carga la genealogía completa en memoria RAM utilizando estructuras de grafos y árboles binarios balanceados, eliminando las consultas lentas recursivas a la base de datos.

2. Compresión Dinámica

Aplica la regla multinivel de compresión dinámica: si un distribuidor intermedio no se activó con puntos en el mes, el motor lo salta automáticamente y sube el volumen a la línea ascendente calificada.

3. Dispersión Contable

Calcula Bono de Patrocinio (primer nivel), Bono Residual Unilevel (múltiples niveles), Bono Generacional VIP y Bono de Ahorro, acreditando directamente las billeteras virtuales con precisión al centavo.

cierre_engine/main.go • Orquestador de Cierre
package main import ( "fmt" "sync" "sifrah/cierre/engine" "sifrah/cierre/db" ) func ProcesarCierreMasivo(periodoID string) { mongoClient := db.GetConnection() arbolGenealogico := engine.CargarRedEnMemoria(mongoClient, periodoID) var wg sync.WaitGroup wg.Add(3) // Procesamiento concurrente masivo con Goroutines go func() { defer wg.Done(); engine.CalcularRangosLiderazgo(arbolGenealogico) }() go func() { defer wg.Done(); engine.CalcularBonoResidualUnilevel(arbolGenealogico) }() go func() { defer wg.Done(); engine.CalcularBonoGeneracionalVIP(arbolGenealogico) }() wg.Wait() engine.DispersarSaldosBilletera(mongoClient, periodoID) fmt.Println("✅ Cierre completado exitosamente en 12.4s") }

Protección legal de la empresa contra diagnósticos irresponsables.
